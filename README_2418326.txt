2. HOW TO RUN TESTS
================================================================================

RECOMMENDED - Run all tests together:
	pytest -v
	
	Expected output: 130 passed in ~21 seconds
	
	This runs all test files:
		• test_models_2418326.py (64 tests)
		• test_app_2418326.py (45 tests)
		• test_integration_2418326.py (14 tests)
		• test_performance_2418326.py (6 tests)
		• test_security_2418326.py (1 test)

RUNNING INDIVIDUAL TEST FILES:

	a) Models Testing (Book, Cart, User, Order, PaymentGateway):
		pytest tests/test_models_2418326.py -v
		Expected output: 64 passed

	b) Application Testing (Flask routes and functionality):
		pytest tests/test_app_2418326.py -v
		Expected output: 45 passed
		
	c) Integration Testing (Complete user workflows):
		pytest tests/test_integration_2418326.py -v
		Expected output: 14 passed
		
	d) Performance Testing (Profiling and benchmarks):
		pytest tests/test_performance_2418326.py -v
		Expected output: 6 passed
		
	e) Security Testing (Bandit static analysis):
		pytest tests/test_security_2418326.py -v
		Expected output: 1 passed

RUNNING SPECIFIC TESTS:
	pytest tests/test_models_2418326.py::TestCart -v
	(Runs only Cart-related tests)

RUNNING WITH COVERAGE REPORT:
	pytest --cov=. --cov-report=html
	(Generates HTML coverage report in htmlcov/ directory)

6. TROUBLESHOOTING
================================================================================

If tests don't run:
	a) Ensure you're in the project root directory
	b) Check Python version: python --version (requires 3.12+)
	c) Verify all dependencies installed: pip list
	d) Reinstall dependencies: pip install -r requirements.txt
	e) Try alternative command: python -m pytest -v

If "ModuleNotFoundError: No module named 'bcrypt'":
	a) Ensure bcrypt installed: pip install bcrypt==4.1.1
	b) Check if using correct Python environment
	c) If using virtual environment, ensure it's activated

If Flask import errors occur:
	a) Install Flask directly: pip install flask==3.0.3
	b) Verify Flask installation: python -c "import flask; print(flask.__version__)"

If tests run but some fail:
	a) This may indicate environment-specific issues
	b) Check that all dependencies match requirements.txt versions
	c) Ensure no conflicting packages installed
	d) All 130 tests should pass in a clean environment

For CI/CD pipeline issues:
	a) Check GitHub Actions tab for detailed error logs
	b) Verify workflow file exists: .github/workflows/testing-pipeline-2418326.yml
	c) Ensure repository has Actions enabled
